# aws-zukan 画面設計書

**バージョン:** 0.1
**作成日:** 2026-06-26

既存アプリの操作感（カード一覧・詳細・タブ）を踏襲する。最初の版は SCR-01〜05、SCR-06/07 は将来。

---

## 画面一覧

| ID | 画面 | 実体 | Phase |
|---|---|---|---|
| SCR-01 | サービス図鑑 一覧 | サービス層の一覧 | 1 |
| SCR-02 | サービス詳細 | サービス層の1件 | 1 |
| SCR-03 | 構成パターン図鑑 一覧 | 構成パターン層を目的で引く | 1 |
| SCR-04 | 構成パターン詳細 | 構成パターン層の1件 | 1 |
| SCR-05 | 比較ビュー | 構成パターン層を評価軸で並べる | 1 |
| SCR-06 | アンチパターン集 | 構成パターン層を「不適合」で絞る | 2 |
| SCR-07 | 設計の確認 | 要件タグから逆引き | 2 |

> SCR-03/05/06/07 は同じ「構成パターン層」データの見せ方違い。データの形を先に固め、画面は薄く作る。

## 共通レイアウト

```
┌───────────────────────────────────────────────┐
│ ヘッダー：aws-zukan  [サービス] [構成パターン] [比較] 🔍検索 │
├───────────────────────────────────────────────┤
│                                               │
│   （各画面の本体）                              │
│                                               │
└───────────────────────────────────────────────┘
```

- 上部タブで「サービス図鑑／構成パターン図鑑／比較」を切り替える。
- 検索はヘッダー常設。アクセシビリティ（ラベル・キーボード操作・色だけに頼らない）を全画面で守る。

## SCR-01 サービス図鑑 一覧

```
┌ 絞り込み ──────┐ ┌ サービス ─────────────────────┐
│ カテゴリ ▾      │ │ ┌────────┐ ┌────────┐ ┌────────┐ │
│ 難易度  ▾      │ │ │ EC2    │ │ S3     │ │ Lambda │ │
│ 無料枠 □有 □無 │ │ │ 仮想… │ │ 保存… │ │ 関数… │ │
│ [検索______]   │ │ │ 計算  │ │ 保存  │ │ 計算  │ │
└───────────────┘ │ └────────┘ └────────┘ └────────┘ │
                   └──────────────────────────────────┘
```

- カード：サービス名・一言・カテゴリバッジ・難易度・無料枠アイコン。
- カード選択で SCR-02 へ。件数が増えても全件を一度に描画しない（ページング／仮想化）。

## SCR-02 サービス詳細

```
┌───────────────────────────────────────────────┐
│ Amazon EC2   [カテゴリ:コンピューティング] ★お気に入り │
│ 一言：企業システム用の仮想サーバー基盤            │
├── タブ：概要 / 使いどころ / 運用・統制 / 関連 ────┤
│ 使う場面 / 向かない場面                          │
│ 本番利用の前提（IAM・監視・ログ・バックアップ…）   │
│ 関連サービス（ALB・Auto Scaling…）  代替候補（ECS…）│
│ 導入の難易度：技術● 運用● 社内調整●              │
│ 共通ルール：[ログ・監査] [暗号化] [ネットワーク] → │
│ 公式：概要 / 料金 / クォータ / セキュリティ        │
│ 更新日 2026-06-26 ・ 確認日 2026-06-26           │
└───────────────────────────────────────────────┘
```

- 「共通ルール」はリンクで共通ページへ（各サービスに重複記載しない）。
- 関連・代替サービスは他サービス詳細へ遷移できる。

## SCR-04 構成パターン詳細

```
┌───────────────────────────────────────────────┐
│ 目的：コーポレートサイト／LP／ドキュメントサイトの公開 │
├───────────────────────────────────────────────┤
│ ✅ 標準推奨構成：S3 + CloudFront + Route 53 + ACM │
│    理由：常時稼働サーバー不要・配信中心            │
│ ⚠ 不適合になりやすい構成：EC2 上に Web サーバー   │
│    なぜ：この要件では運用負荷が相対的に高い        │
│ 必須になりやすい統制：HTTPS / CF経由のみ / ログ     │
│ 任意要素：WAF / CI-CD / アクセスログ              │
├ 評価（8観点）────────────────────────────────┤
│ セキュリティ ○  可用性 ◎  運用負荷 ◎  コスト ◎    │
│ 拡張性 ○  統制適合 ○  移行容易 ○  ベンダー依存 △   │
│ 代替案：Amplify Hosting / コンテナ・EC2 上の Web   │
└───────────────────────────────────────────────┘
```

- 「良し悪し」は断定せず、前提条件つきで示す（標準推奨／不適合になりやすい）。
- 構成中のサービス名は SCR-02 へリンク。

────────────┼──────────────┼────────────────┼──────────────

可用性      │   ◎          │   △            │   ○
運用負荷    │   ◎          │   △            │   ◎
コスト      │   ◎          │   △            │   ○
拡張性      │   ○          │   ○            │   ○
統制適合    │   ○          │   ○            │   △
移行容易    │   ○          │   ○            │   △
